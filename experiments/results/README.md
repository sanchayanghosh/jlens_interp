# Jacobian Lens results

`raw_results.json` is produced by the full Modal run. It contains generated responses,
regenerated behavioral outcomes, exact token positions, per-layer answer/option/vocabulary
scores, and top-token exports for both the Jacobian Lens and vanilla Logit Lens.

`summary.json` and `preliminary_results.md` are produced by
`scripts/analyze_jlens_results.py`.

The committed run uses `unsloth/Meta-Llama-3.1-8B-Instruct`, greedy decoding, a 256-token
ceiling, and an H100 80GB. Historical labels came from a different Together model, so the
analysis treats the behavior regenerated by this exact checkpoint as primary and retains
ambiguous/null cases.

`expanded_summary.json` is produced by `modal_app.py::run_expanded`. It covers all 117
historically sycophantic cases plus 117 strict-honest, answer-letter-matched controls (936
prompts). It contains generated responses, item-level outcome metrics, and mean/SD/SE
layerwise aggregates at all six decision positions without duplicating the full raw logits.

`commitment_raw.json` is produced by `modal_app.py::run_commitment`. It covers 330 prompts:
85 same-question sycophantic/warranted-agreement pairs plus 122 matched
sycophantic/resistant pairs. `commitment_findings.json` and `commitment_results.md` are
produced by `scripts/analyze_commitment_results.py`; they report the answer-key-free primary
detector and a discovery/held-out open analysis of J-space concepts.

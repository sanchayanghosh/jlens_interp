# Jacobian Lens results

`raw_results.json` is produced by the full Modal run. It contains generated responses,
regenerated behavioral outcomes, exact token positions, per-layer answer/option/vocabulary
scores, and top-token exports for both the Jacobian Lens and vanilla Logit Lens.

`summary.json` and `preliminary_results.md` are produced by
`scripts/analyze_jlens_results.py`.

The committed run uses `unsloth/Meta-Llama-3.1-8B-Instruct`, greedy decoding, a 256-token
ceiling, and an H100 80GB. Historical labels came from a different Together model, so the
analysis treats the behavior regenerated by this exact checkpoint as primary and retains
ambiguous/null cases.
